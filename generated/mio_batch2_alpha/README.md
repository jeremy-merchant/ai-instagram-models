## 제작 방식

1. 레퍼런스 원본을 `images --edit` 기반으로 재생성 — 구도·배경·조명·의상·포즈 유지, 인물 얼굴만 미오로 교체.
2. 흰 낙서/모자이크가 있던 컷(`ref_02·04·08·09·10`)은 **①낙서·모자이크 제거 패스 → ②미오 얼굴·흑발 패스** 2단계로 처리(얼굴을 잘라 붙이는 방식 폐기 — 직전 `ref_02` 폐기 원인).
3. 원본이 금발/적갈색이던 컷(`ref_02·04·08·10`)은 피드 정체성 유지를 위해 흑발로 통일.
4. 후처리: `Image.fromarray(np.array(img.convert('RGB')))`로 픽셀만 복사 후 `JPEG(quality=95, subsampling=0)`. 세그먼트 검사 결과 APP0(JFIF)·DQT·SOF0·DHT·SOS만 존재 — `c2pa·C2PA·caBX·jumb·xmp·Exif·ICC_PROFILE` **0건**.
